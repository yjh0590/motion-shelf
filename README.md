# Motion Shelf

복사해서 바로 쓰는 웹 모션·UI 요소 900종. 요소마다 업계에서 통용되는 영어 정식 명칭, AI에게 그대로 줄 프롬프트, 코드가 함께 있다. 프롬프트 가이드, 모션 용어집, 레퍼런스 사이트도 탭으로 정리돼 있다.

https://motion.oddz.click

단일 `index.html` (빌드 없음). 9개 카테고리에 100종씩: 버튼, 로더, 텍스트 애니메이션, 카드, 마이크로 인터랙션, UI 컴포넌트, 배경, 스크롤 애니메이션, 이징 함수.

## 데모 추가

파일 안의 `D` 배열에 `{ name, ko, kw, prompt, cat, desc, html, css, js? }` 하나를 넣는다.

- `name`: 영어 정식 명칭 (Hover.css, Animate.css, shadcn/ui, W3C APG, React Bits 등에서 쓰는 이름). 카드 제목이 된다.
- `ko`: 한국어 이름. 제목 아래에 작게 나온다.
- `cat`: 위 9개 카테고리 중 하나. 새 카테고리를 만들면 `CAT_EN`에 영어 이름도 넣는다.
- 클래스 이름·`@keyframes`·`@property`·`id`는 다른 데모와 겹치지 않게 고유한 접두사를 쓴다.
- 비슷한 데모가 여럿이면 기존 "추가 N종" 블록처럼 표에서 생성해도 된다. `html`·`css`에는 완성된 문자열이 들어가야 복사한 코드가 그대로 동작한다.

데모는 카드가 화면 근처에 처음 왔을 때 한 번 시작한다.
