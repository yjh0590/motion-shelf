Motion Shelf

페이지 만들 때 꺼내 쓰는 모션·UI 요소 서랍. 대부분 순수 CSS이고, 필요한 것만 몇 줄의 JS를 씁니다. 미리보기를 만져 보고, AI에게 시킬 땐 카드의 프롬프트를, 직접 넣을 땐 코드를 복사하세요.

프롬프트 쓰는 법

AI에게 모션을 부탁할 때 "예쁘게 움직이게 해줘"라고 하면 매번 다른 결과가 나와요. 아래 다섯 가지를 채워 말하면 한 번에 원하는 모양이 나옵니다. 전부 채울 필요는 없고, 빠진 건 AI가 알아서 정해요.

  1. 대상무엇에주요 버튼, 카드, 제목
  2. 트리거언제호버, 클릭, 화면에 들어올 때, 계속 반복
  3. 움직임어떻게위로 2px, 서서히 나타남, 회전, 색 변화
  4. 느낌속도와 이징0.3초, 부드럽게, 톡 튀게
  5. 조건제약순수 CSS, 라이브러리 없이, 기존 색 유지

✗ 버튼 좀 예쁘게 움직이게 해줘

✓ 주요 버튼에 마우스를 올리면 위로 2px 떠오르면서 버튼 색 빛이 번지게 해줘. 0.3초 동안 부드럽게, 순수 CSS로.

알아두면 프롬프트가 쉬워지는 단어

이징easing
속도가 변하는 곡선. ease-out은 빠르게 출발해 부드럽게 멈춰서 가장 무난해요.
듀레이션duration
걸리는 시간. 버튼·호버는 0.2~0.4초가 적당해요.
딜레이delay
시작하기 전에 기다리는 시간.
스태거stagger
여러 요소가 시차를 두고 차례로 움직이는 것.
오버슈트overshoot · spring
목표를 살짝 지나쳤다 돌아오는 것. "톡 튀는" 느낌의 정체예요.
트랜지션transition
호버처럼 상태가 바뀔 때 A에서 B로 한 번 변하는 것.
키프레임keyframes
여러 단계를 정해 두고 재생하거나 반복하는 애니메이션.
스크롤 연동scroll-driven
스크롤한 만큼 진행되는 것. "화면에 들어올 때 한 번"은 scroll reveal이라고 해요.
마이크로 인터랙션micro-interaction
클릭·토글 같은 작은 조작에 돌려주는 짧은 반응.
움직임 줄이기prefers-reduced-motion
멀미가 있는 사람을 위한 기기 설정. "이 설정이면 애니메이션 끄기"를 조건에 넣으면 좋아요.

카드의 프롬프트를 복사해 숫자와 색만 바꿔 쓰세요. 코드까지 같이 붙여넣고 "이 느낌으로 내 사이트에 맞춰줘"라고 하면 더 정확해요. 회색 영어 키워드는 AI나 검색에 그대로 쓰면 통하는 이름이에요.
