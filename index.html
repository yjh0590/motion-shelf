프롬프트 쓰는 법

AI에게 모션을 부탁할 때 "예쁘게 움직이게 해줘"라고 하면 매번 다른 결과가 나와요. 아래 다섯 가지를 채워 말하면 한 번에 원하는 모양이 나옵니다. 전부 채울 필요는 없고, 빠진 건 AI가 알아서 정해요.

  1. 대상무엇에주요 버튼, 카드, 제목
  2. 트리거언제호버, 클릭, 화면에 들어올 때, 계속 반복
  3. 움직임어떻게위로 2px, 서서히 나타남, 회전, 색 변화
  4. 느낌속도와 이징0.3초, 부드럽게, 톡 튀게
  5. 조건제약순수 CSS, 라이브러리 없이, 기존 색 유지

✗ 버튼 좀 예쁘게 움직이게 해줘

✓ 주요 버튼에 마우스를 올리면 위로 2px 떠오르면서 버튼 색 빛이 번지게 해줘. 0.3초 동안 부드럽게, 순수 CSS로.

  • 카드의 프롬프트를 복사해 숫자와 색만 바꿔 쓰세요.
  • 코드까지 같이 붙여넣고 "이 느낌으로 내 사이트에 맞춰줘"라고 하면 더 정확해요.
  • 카드의 회색 영어 키워드는 AI나 검색에 그대로 쓰면 통하는 이름이에요.
  • 다섯 칸에 넣을 말이 안 떠오르면 용어 사전에서 골라 쓰세요.

모션 용어 사전

프롬프트 공식의 다섯 칸에 넣을 단어를 칸별로 모았어요. 한국어로 말해도 되지만, 옆의 영어 이름을 같이 쓰면 AI도 검색도 더 정확하게 알아들어요.
